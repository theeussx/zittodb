COMO FUNCIONA

Você clica.
O sistema explica.

O ZittoDB é uma interface para ferramentas Android existentes, não um substituto para elas.

01Interface Reactusuário escolhe a ação
→
02Bridge tipadaoperação estruturada
→
03Tauri / Rustvalida e monta argv
→
04ADB · scrcpy · fastbootferramenta externa
→
05Resultado localinterface e auditoria
Nenhum processo é executado pelo frontend. O backend resolve o serial, valida argumentos e controla o ciclo de vida.

SEGURANÇA E PRIVACIDADE

Fronteiras claras.
Decisões explícitas.

As afirmações abaixo refletem o código e a documentação atuais do projeto.

Ler modelo de segurança no GitHub ↗
01
Backend no controle

O frontend não executa processos; o Rust controla allowlist, argumentos e timeouts.

02
Dispositivo explícito

Cada operação é direcionada ao serial selecionado, sem alvo implícito.

03
Confirmações destrutivas

Operações sensíveis exigem confirmação digitada conforme a implementação.

04
Dados no filesystem local

Configurações, logs e auditoria permanecem na máquina; a consulta de update usa metadados públicos do GitHub.
