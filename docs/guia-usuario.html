Requisitos de sistema

Antes de começar, certifique-se de que seu computador atende aos requisitos:

obrigatório 🐧

Sistema operacional

Qualquer distribuição Linux 64 bits (amd64): Debian, Ubuntu, Fedora, Arch, Mint, Pop!_OS etc. Funciona em Wayland ou X11.

obrigatório 🔧

ADB

Android Debug Bridge — a ferramenta que fala com o celular. Instale pelo gerenciador de pacotes da sua distro.

opcional 📱

scrcpy

Espelhamento e gravação de tela. Recomendamos a versão 3.2+ para funcionar com Android 15.

opcional ⚡

fastboot

Para operações avançadas em modo bootloader/recovery (flash, reinicialização, etc).

💡
Requisitos de hardware
Você precisa de no mínimo 2 GB de RAM e 50 MB de espaço em disco. O Zittodb é leve o suficiente para rodar em computadores antigos ou com modo de economia de energia.

Instalação

Escolha o formato de acordo com a sua distribuição Linux:

🚀 Método 1 — AppImage (qualquer distro)

O AppImage é um arquivo único, portátil, que não precisa de instalação. Basta baixar, dar permissão e executar:

# 1. Dê permissão de execução: chmod +x Zittodb-*.AppImage # 2. Execute o app: ./Zittodb-*.AppImage
✨
Dica
Mova o AppImage para ~/.local/bin/ e ele aparecerá automaticamente no menu de aplicativos da maioria das distros.

📦 Método 2 — Pacote .deb (Debian, Ubuntu, Mint, Pop!_OS)

Para distribuições baseadas em Debian, o pacote .deb instala o app no sistema:

# Instale com apt (resolve dependências automaticamente): sudo apt install ./Zittodb-*.deb

🔧 Instalar as ferramentas do Android

O Zittodb usa as ferramentas oficiais do Android instaladas no seu sistema. Instale-as com um dos comandos abaixo:

# Debian / Ubuntu / Mint / Pop!_OS: sudo apt update && sudo apt install adb scrcpy fastboot # Fedora: sudo dnf install android-tools scrcpy # Arch Linux: sudo pacman -S android-tools scrcpy
⚠️
Atenção: scrcpy no Ubuntu 22.04 LTS
A versão do scrcpy nos repositórios do Ubuntu 22.04 é antiga (1.25) e não funciona com Android 15. Se você tem um dispositivo novo, baixe a versão mais recente no site oficial do scrcpy.
🔍
Depois de instalar tudo, rode make check-deps dentro da pasta do código-fonte para conferir se todas as ferramentas foram detectadas e ver suas versões.

Configurar seu dispositivo Android

Antes de conectar o celular ao computador, você precisa habilitar a depuração USB:

📱 Abra as Configurações do celular

Vá até a tela principal de Configurações do Android.

ℹ️ Toque em "Sobre o telefone"

Role até encontrar a opção "Número de compilação" (ou "Build number").

👆 Toque 7 vezes em "Número de compilação"

Isso habilita as "Opções de desenvolvedor". Você verá uma mensagem de confirmação.

🔧 Volte e abra "Opções de desenvolvedor"

Esse menu novo aparece agora na tela principal de Configurações.

✅ Ative "Depuração USB"

Confirme a caixa de diálogo que aparece.

🔌 Conecte o cabo USB

Use um cabo de dados (não apenas de carregamento). Conecte ao computador.

🔐 Aceite a autorização RSA

No celular, marque "Sempre permitir deste computador" e toque em OK.

📶
Conexão por Wi-Fi (sem cabo)
Depois de parear por USB uma vez, você pode conectar sem fio: certifique-se que o celular e o computador estão na mesma rede Wi-Fi, depois use a opção "Conectar por Wi-Fi" no Zittodb, ou execute adb connect IP_DO_CELULAR:5555.

🧪 Verificar se está funcionando

No terminal, rode:

adb devices -l

Se aparecer o serial do seu dispositivo com o status device , está tudo pronto para abrir o Zittodb!

Perguntas frequentes (FAQ)

Resolvendo os problemas mais comuns:

Desbloqueie a tela do celular e aceite a caixa de diálogo RSA que aparece no aparelho. Se a caixa não aparecer:

1️⃣ Vá em Opções de desenvolvedor → Revogar autorizações de depuração USB
2️⃣ Desconecte e reconecte o cabo
3️⃣ Aceite a nova solicitação.

Verifique estas possibilidades:

🔌 Confira se o cabo suporta dados (muitos cabos servem apenas para carregar)
✅ Certifique-se que Depuração USB está ativada
🔄 Troque a porta USB ou o cabo
♻️ Rode adb kill-server && adb start-server e reinicie o Zittodb.

Verifique a versão do scrcpy: Android 15 exige scrcpy 3.2 ou mais nova. A versão que vem no Ubuntu 22.04 é muito antiga. Baixe a versão mais recente no site oficial e configure o caminho do executável em Configurações → Ferramentas → scrcpy.
